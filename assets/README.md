# assets

## Manrope-Bold.ttf

Шрифт [Manrope](https://github.com/sharanda/manrope) — Mikhail Sharanda,
лицензия **SIL Open Font License 1.1** (https://scripts.sil.org/OFL).

Распространяется вместе с проектом на условиях OFL: разрешено использовать,
изучать, изменять и распространять, в том числе в составе другого ПО. Лицензия
OFL относится только к этому файлу; код проекта — под MIT (см. `../LICENSE`).

Используется в `render_cards.py` для карточек кампаний, у которых Twitch ещё не
выложил арт значка: на карточку выводится название. Встроенный шрифт Pillow не
подошёл — он не покрывает кириллицу.
